# Zerong Wang — Academic Website

Static GitHub Pages site for Zerong Wang, Lecturer in Economics at Zhejiang University of Finance and Economics.

The public website is [zerongwong.github.io](https://zerongwong.github.io/).
Changes pushed to the `main` branch are published by the included GitHub Pages workflow.

## Updating the site

- Replace `files/Zerong_Wang_CV.pdf` whenever the CV changes.
- Update the publication lists in `index.html`, `research/index.html`, and `publications/index.html` when a paper changes status.
- Do not add an empty Programming page. Add `Data & Code` only when public replication files or software are available.
